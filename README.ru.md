# Управление Skills и MCP в DSH

Плагин боковой панели DSH для управления локальными Skills и MCP-серверами. Интерфейс использует токены темы DSH, не встраивает iframe и сохраняет пункт `Skills и MCP`.

Глобальный каталог `~/.agents/skills` не попадает в каталог Skills модели. В DSH добавляются только явно синхронизированные Skills.

![Управление Skills](docs/screenshots/overview.png)

## Возможности

- Поиск, создание, редактирование, включение, отключение и удаление пользовательских и проектных Skills.
- Скрытие глобального каталога Agent из каталога модели и синхронизация только выбранных Skills.
- Синхронизация символическими ссылками или копированием, отображение режима, предпросмотр и резервная копия перед заменой.
- Множественный выбор флажками и пакетное удаление.
- Импорт ZIP-пакетов Skills перетаскиванием или выбором файла.
- Редактирование записей MCP Manager и автономных MCP в форме или JSON, проверка подключения, переподключение, импорт и запрос одобрения Host.
- Автообновление установок npm и примечания GitHub Releases.

## Установка

```bash
dsh plugin --profile desktop add dsh-capability-switch
```

Для установки из исходников клонируйте репозиторий, выполните `npm install --ignore-scripts` и выберите каталог в DSH через **Плагины → Добавить плагин**. Текущая версия проверена на DSH `0.2.3-alpha.2`.

## Языки

Интерфейс следует настройке **DSH → Общие → Язык** и поддерживает восемь языков: `zh`, `en`, `ja`, `es`, `fr`, `de`, `ru`, `pt`. При смене языка интерфейс обновляется автоматически.

Списки Skills и MCP не переводятся. Имена, описания, содержимое SKILL.md, команды и URL отображаются на исходном языке.

## Данные и разрешения

Доступ к локальным файлам `~/.dsh/skills`, `~/.agents/skills`, `~/.dsh/capability-switch` и `cordis.patch.yml` активного профиля DSH. Сетевой доступ ограничен реестром npm (автообновление) и API GitHub Releases (примечания к выпускам). Skills, конфигурация MCP и учётные данные не загружаются.
